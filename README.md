# Giulia Novars — предпросмотр сайта

Девять редактируемых страниц в каталоге `docs/`. Маршруты сохраняют адреса основных страниц оригинала.

| Страница | Путь |
| --- | --- |
| Главная | `/` |
| Реализованные проекты | `/realizedprojects/` |
| Салоны | `/shops/` |
| Гардеробные | `/catalog/dressingroom/` |
| О компании | `/about/` |
| Производство | `/manufacture/` |
| Контакты | `/contacts/` |
| Карта салонов | `/map/` |
| Мебель для всей квартиры и дома | `/mebel-dlya-vsey-kvartiry-i-doma/` |

Маршрут карты ведёт на интерактивную карту оригинала. На стенде работают меню, выбор города, просмотр галерей, сортировка сохранённых проектов и демонстрационные формы. Полный каталог и связанные карточки открываются на официальном сайте. Все страницы содержат `noindex, nofollow, noimageindex`.

Для локального просмотра запусти `python3 -m http.server 8000 --directory docs` из корня репозитория. GitHub Pages публикует статическую сборку через GitHub Actions. На этапе публикации открытые изображения и видео сохраняются в сборке. Для файлов, которые исходный сервер не отдал, сборка сохраняет исходный URL.
