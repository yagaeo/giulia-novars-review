# Рабочая копия Giulia Novars

Стенд для редактирования и согласования страниц с командой Giulia Novars. В `docs/` находятся 44 маршрута, из них 43 соответствуют страницам официального сайта, а 1 содержит посадочную «Мебель для всей квартиры и дома».

| Группа | Количество |
| --- | ---: |
| Ранее существовавшие маршруты, включая обновленную карту и посадочную | 9 |
| Новые основные разделы | 19 |
| Салоны | 4 |
| Реализованные проекты | 4 |
| Модели кухонь | 3 |
| Модели гардеробных | 3 |
| Новости | 2 |

Полный состав и источники указаны в [реестре маршрутов](docs-meta/page-inventory.tsv). Для новых страниц редактируй `docs/<маршрут>/index.html`. Сборка добавляет к содержимому общую шапку и подвал из существующей страницы `docs/about/index.html`. Хлебные крошки новых страниц берутся из `tools/section-breadcrumbs.json`. Общие стили и сценарии лежат в `docs/assets/`. Ссылки на перенесенные маршруты сборка делает относительными, а остальные ссылки на страницы клиента направляет на оригинал.

## Просмотр и публикация

Из корня репозитория запусти:

```sh
python3 tools/prepare_pages.py docs local-preview/giulia-novars-review
python3 -m http.server 8000 --directory local-preview
```

Открой `http://localhost:8000/giulia-novars-review/`. Для повторной сборки используй новый пустой выходной каталог. Дополнительный аргумент `--media-budget` задает время скачивания необязательных медиа. При недоступности оригинального изображения или видео сборка сохраняет исходный URL. Для шрифтов сборка требует локальную копию.

Существующий процесс [Publish preview](.github/workflows/pages.yml) собирает и публикует версию из `main` на [GitHub Pages](https://yagaeo.github.io/giulia-novars-review/).

## Карта и формы

Маршрут `/map/` и карты в 4 перенесенных салонах используют `docs/map/salons.json`. У каждой записи есть ID источника, адрес страницы салона, координаты и опубликованные контакты. Для перенесенных салонов поле `link` указывает путь к локальной странице относительно файла данных. Параметр `?salon=` принимает код или ID салона. Подложка OpenStreetMap отображается через Leaflet. Данные салонов работают без Bitrix.

Формы демонстрационные. Сайт показывает результат проверки формы в браузере и не отправляет заявки, письма или файлы. У всех страниц есть директивы `noindex,nofollow,noimageindex`, в `robots.txt` сохранен `Disallow: /`. Стенд доступен по прямой ссылке.
